# 01 - 项目总览

## 这是什么？

**AI Photograph Creator（AI 摄影创作者）** 是一个 AI 图片生成网站。

用户通过表单选择图片类型、比例、风格、场景、留白等选项，然后输入主体描述，系统会自动把这些选项组装成专业的英文提示词（Prompt），最后调用阿里云的 AI 图片生成 API 生成图片。

> **一句话总结**：你填表单 → 系统拼英文提示词 → 调用 AI 画图 → 返回结果给你看。

---

## 核心功能

| 功能 | 说明 |
|------|------|
| 结构化表单 | 图片类型、比例、风格、场景、留白 — 五个维度可选 |
| 提示词组装 | 自动将中文选项转换为高质量英文提示词 |
| AI 图片生成 | 调用阿里云 DashScope `qwen-image-2.0` 模型 |
| 用户系统 | 注册、登录、JWT 认证 |
| 积分系统 | 新用户送 5 积分，每次生成消耗 1 积分，失败退还 |
| 生成历史 | 查看所有生成记录，网格布局展示 |
| 中英双语 | 支持中文和英文界面切换 |

---

## 整体架构（三部分组成）

```
┌──────────────────────┐       ┌──────────────────────┐       ┌──────────────────────┐
│    前端 (Frontend)    │  HTTP │   后端 (Backend)      │  SQL  │   数据库 (Database)   │
│   React + Vite       │ ────→ │   FastAPI + Python    │ ────→ │   PostgreSQL         │
│   用户看到的网页       │ ←──── │   处理业务逻辑         │ ←──── │   存储用户/图片数据    │
└──────────────────────┘       └──────────┬───────────┘       └──────────────────────┘
                                          │
                                          │ HTTP (API 调用)
                                          ▼
                               ┌──────────────────────┐
                               │  阿里云 DashScope     │
                               │  qwen-image-2.0 模型  │
                               │  根据提示词生成图片    │
                               └──────────────────────┘
```

**类比理解** — 就像去餐厅吃饭：

| 角色 | 对应部分 |
|------|----------|
| 菜单和餐桌（你看到和操作的东西） | 前端 (Frontend) |
| 厨师（接收订单、处理、组装成品） | 后端 (Backend) |
| 冰箱/仓库（存储食材和订单记录） | 数据库 (Database) |
| 外卖供应商（提供核心"画图"能力） | DashScope API |
