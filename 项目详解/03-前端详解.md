## 3.2 应用入口：`main.tsx` → `App.tsx`

### main.tsx — React 挂载点

```tsx
createRoot(document.getElementById('root')!).render(
  <StrictMode>
    <App />
  </StrictMode>,
)
```

> 这是 React 应用的**第一行代码**。它找到 `index.html` 中的 `<div id="root">`，把整个 React 应用渲染进去。`StrictMode` 在开发模式下会额外检查潜在问题。

### App.tsx — 应用主体

```tsx
function App() {
  return (
    <AuthProvider>        {/* ① 全局用户状态 */}
      <LocaleProvider>    {/* ② 全局语言状态 */}
        <AppContent />    {/* ③ 路由 + 页面 */}
      </LocaleProvider>
    </AuthProvider>
  );
}
```

**三层嵌套结构**：最外层是 AuthProvider（管理登录状态），中间是 LocaleProvider（管理语言），最里面是路由。

## 3.3 路由设计

```tsx
<Routes>
  {/* 公开页面 — 不用登录就能访问 */}
  <Route path="/login" element={<LoginPage />} />
  <Route path="/register" element={<RegisterPage />} />

  {/* 受保护页面 — 需要登录 */}
  <Route element={<PrivateRoute />}>    ← 路由守卫
    <Route element={<Layout />}>        ← 带侧边栏的布局
      <Route index element={<HomePage />} />        {/* / */}
      <Route path="history" element={<HistoryPage />} />  {/* /history */}
      <Route path="points" element={<PointsPage />} />    {/* /points */}
    </Route>
  </Route>
</Routes>
```

### PrivateRoute — 路由守卫

```tsx
function PrivateRoute() {
  const { user, isLoading } = useAuth();

  if (isLoading) return <LoadingSpinner />;   // 正在检查登录状态 → 显示 loading

  if (!user) return <Navigate to="/login" replace />;  // 未登录 → 跳转到登录页

  return <Outlet />;  // 已登录 → 显示子路由内容
}
```

> **`<Outlet />` 是什么？** 它代表子路由的内容。当访问 `/` 时，`<Outlet />` 渲染 `<HomePage />`；访问 `/history` 时，渲染 `<HistoryPage />`。

## 3.4 全局状态管理

React 中跨组件共享数据，使用 **Context（上下文）** 机制。

### AuthContext（用户认证状态）

```tsx
interface AuthContextType {
  user: User | null           // 当前用户信息，null = 未登录
  token: string | null        // JWT 令牌
  login: (email, password) => Promise<void>     // 登录
  register: (email, password, nickname) => Promise<void>  // 注册
  logout: () => void          // 登出
  updateBalance: (newBalance: number) => void   // 更新积分余额
  isLoading: boolean          // 是否正在加载中
}
```

**工作流程**：

```
页面加载
  ↓
① 从 localStorage 读取之前保存的 token
  ↓
② 没有 token → isLoading = false, user = null → 显示登录页
  ↓
③ 有 token → 调用 /api/v1/auth/me 验证
  ↓
④ 验证成功 → user = 用户信息 → 自动登录
  ↓
⑤ 验证失败 → 清除 token → user = null → 显示登录页
```

**登录/注册流程**：
```tsx
const login = async (email, password) => {
    const response = await api.login({ email, password })
    setAuthToken(response.token)             // 设置 API 客户端的 token
    setUser(response.user)                   // 更新用户状态
    localStorage.setItem('token', response.token)  // 持久化存储
}
```

> **为什么要存到 localStorage？** 如果只存在内存中，用户刷新页面后登录状态就丢失了。localStorage 是浏览器的持久化存储，刷新后仍然存在。

### LocaleContext（语言偏好）

```tsx
interface LocaleContextType {
  locale: 'zh' | 'en'          // 当前语言
  setLocale: (locale) => void  // 切换语言
}
```

语言偏好也存到 `localStorage`，切换后自动调用 `i18n.changeLanguage()` 更新界面文字。

## 3.5 页面详解

### HomePage（首页）⭐ 核心页面

整个应用最重要的页面，分为三部分：

#### ① 加载状态（骨架屏）

```tsx
if (!options) {
  return (
    <div>
      <Skeleton className="h-8 w-64" />   {/* 模拟标题 */}
      <Skeleton className="h-4 w-96" />   {/* 模拟副标题 */}
      <Skeleton className="h-64 w-full" /> {/* 模拟表单 */}
    </div>
  );
}
```

> **骨架屏 (Skeleton)** 在数据加载时显示灰色占位块，让用户知道内容正在加载中，比空白页面体验更好。

#### ② 生成表单

表单中每个维度的结构都一样：

```tsx
<label>
  <Image size={16} />  {/* 图标 */}
  {t("home.imageType")}  {/* 标签（自动根据语言显示中文/英文）*/}
</label>
<ChipSelector
  options={options.image_types}  {/* 所有可选选项 */}
  value={form.image_type}        {/* 当前选中的值 */}
  onChange={(v) => handleChange("image_type", v)}  {/* 选中时更新 */}
  columns={5}                    {/* 每行 5 个 */}
/>
```

`handleChange` 实现：
```tsx
const handleChange = (field: keyof FormData, value: string) => {
    setForm((prev) => ({ ...prev, [field]: value }));
};
```

> **`...prev`（展开运算符）**：创建一个新对象，复制旧对象的所有属性，然后覆盖指定字段。这是 React 中更新状态的**不可变数据**模式。

#### ③ 提交与结果

```tsx
const handleSubmit = async (e) => {
    e.preventDefault();  // 阻止表单的默认提交行为（页面刷新）
    setLoading(true);
    try {
        const response = await api.generate({ ...form });
        setResult(response);                        // 显示结果
        updateBalance(response.points_balance_after); // 更新积分
    } catch (err) {
        if (err.status === 402) {
            setShowUpgrade(true);  // 积分不足 → 弹出升级弹窗
        } else {
            setError(err.message); // 其他错误 → 显示错误信息
        }
    } finally {
        setLoading(false);  // 无论成功失败，关闭 loading
    }
};
```

#### ④ 结果展示

- 生成成功：显示图片 + 点击放大（Lightbox）+ 可展开看提示词
- 积分不足：弹出升级弹窗（目前是占位 UI）
- 生成失败：显示红色错误信息

### PointsPage（积分页）

亮点是**数字滚动动画**：

```tsx
function AnimatedBalance({ target }: { target: number }) {
    const [display, setDisplay] = useState(0);

    useEffect(() => {
        const duration = 800;  // 动画时长 800ms
        const step = (now) => {
            const progress = Math.min(elapsed / duration, 1);
            const eased = 1 - Math.pow(1 - progress, 3);  // 缓出函数
            setDisplay(Math.round(eased * target));
            if (progress < 1) requestAnimationFrame(step);  // 继续下一帧
        };
        requestAnimationFrame(step);
    }, [target]);

    return <span>{display}</span>;  // 0 → 1 → 2 → ... → target
}
```

> **缓动函数 (Easing)**：`1 - Math.pow(1 - t, 3)` 是一个缓出曲线，数字开始变化快，接近目标时变慢，看起来更自然。

## 3.6 后端通信：`lib/api.ts`

```typescript
const API_BASE = '/api/v1';

async function request<T>(path, options): Promise<T> {
    const res = await fetch(`${API_BASE}${path}`, {
        method,           // GET / POST / PATCH
        headers: {
            'Content-Type': 'application/json',
            'Authorization': token ? `Bearer ${token}` : undefined,  // JWT
        },
        body: body ? JSON.stringify(body) : undefined,
    });

    if (!res.ok) {
        // 统一错误处理：把后端返回的错误信息包装成 Error 对象
        const err = await res.json();
        const error = new Error(err.detail);
        error.status = res.status;  // 附加 HTTP 状态码
        throw error;
    }

    return res.json();  // 解析 JSON 响应
}
```

**导出的 API 方法**：
```typescript
export const api = {
    register: (body) => request('/auth/register', { method: 'POST', body }),
    login: (body) => request('/auth/login', { method: 'POST', body }),
    generate: (body) => request('/generate', { method: 'POST', body, auth: true }),
    getGenerations: (page, size) => request(`/generate?page=${page}&size=${size}`, { auth: true }),
    getPoints: () => request('/points', { auth: true }),
    getOptions: () => request('/options'),
    // ...
};
```

## 3.7 Vite 代理配置：`vite.config.ts`

```typescript
export default defineConfig({
  plugins: [react(), tailwindcss()],
  server: {
    proxy: {
      '/api': {
        target: 'http://localhost:8000',  // 把 /api 请求转发到后端
        changeOrigin: true,
      },
      '/images': {
        target: 'http://localhost:8000',  // 把 /images 请求也转发到后端
        changeOrigin: true,
      },
    },
  },
});
```

> **为什么需要代理？** 开发时前端跑在 `localhost:5173`，后端跑在 `localhost:8000`。如果不配代理，前端请求 `/api/v1/auth/login` 会请求 `localhost:5173/api/v1/auth/login`（不存在）。配置代理后，Vite 自动把 `/api` 开头的请求转发到 `localhost:8000`。

## 3.8 可复用 UI 组件

### Button（按钮）— 支持 5 种样式、3 种尺寸

| 属性 | 可选值 | 说明 |
|------|--------|------|
| `variant` | primary / secondary / outline / ghost / danger | 样式变体 |
| `size` | sm / md / lg | 尺寸 |
| `loading` | true / false | 显示转圈动画，禁用点击 |
| `leftIcon` / `rightIcon` | React 节点 | 左右图标 |

还实现了**点击涟漪效果**：点击按钮时，从鼠标位置扩散出一个半透明圆圈。

### ChipSelector（芯片选择器）

表单中的选项按钮组，选中状态用蓝色高亮：
```tsx
<ChipSelector
  options={[
    { key: "portrait", label: "人像摄影" },
    { key: "landscape", label: "风景摄影" },
    // ...
  ]}
  value={selectedKey}       // 当前选中
  onChange={setSelectedKey} // 点击时更新
  columns={5}               // 每行 5 个
/>
```

### Card（卡片）— 3 种样式

| variant | 效果 |
|---------|------|
| default | 深灰背景 + 细边框 |
| elevated | 带阴影的浮起效果 |
| glass | 毛玻璃：半透明背景 + 模糊 + 细边框 |

### Modal（弹窗）

- 使用 `createPortal` 渲染到 `<body>` 下（避免被父元素的 CSS 影响）
- 点击遮罩层关闭
- 按 ESC 键关闭
- 打开时禁止页面滚动

### Skeleton（骨架屏）

加载占位块，支持自定义宽高和圆角。使用 CSS `shimmer` 动画（光泽扫过效果）。

### TypewriterText（打字机效果）

逐字显示文本，模拟打字效果：
```tsx
<TypewriterText
  text="Create Amazing AI Photos"
  speed={60}      // 每 60ms 显示一个字符
  delay={200}     // 开始前等待 200ms
  showCursor      // 显示闪烁的光标
/>
```

### TiltCard（3D 倾斜卡片）

鼠标悬停时，卡片根据鼠标位置产生 3D 旋转效果：
```tsx
// 根据鼠标在卡片上的位置计算旋转角度
const rotateX = ((y - centerY) / centerY) * -maxTilt;
const rotateY = ((x - centerX) / centerX) * maxTilt;
card.style.transform = `perspective(1000px) rotateX(${rotateX}deg) rotateY(${rotateY}deg)`;
```

## 3.10 暗色主题：`index.css`

整个网站是**暗色主题**，所有颜色定义在 CSS 自定义属性中：

| 色系 | 用途 |
|------|------|
| `dark-50` ~ `dark-900` | 深黑背景，从浅到深 |
| `accent-50` ~ `accent-900` | 蓝色强调色 |
| `text-primary / secondary / tertiary` | 三级文字颜色（白→灰→深灰） |
| `success-400/500/600` | 绿色（成功状态） |
| `red-400/500` | 红色（错误状态） |

自定义动画：
- `fade-in` — 淡入
- `slide-up` — 从下方滑入
- `scale-in` — 缩放弹入
- `shimmer` — 光泽扫过（骨架屏用）
- `breath` — 呼吸灯（生成按钮用）
- `float` — 浮动（背景装饰用）
