## 项目技术栈一览

| 层级 | 技术 | 一句话说明 |
|------|------|-----------|
| 前端框架 | React 19 + TypeScript | 组件化构建网页界面 |
| 前端构建 | Vite | 极速开发服务器和打包 |
| 前端样式 | Tailwind CSS v4 | 用 class 名直接写样式 |
| 前端路由 | react-router-dom v7 | 管理页面跳转 |
| 国际化 | react-i18next | 中文/英文切换 |
| 后端框架 | FastAPI (Python 3.13) | 高性能异步 Web 框架 |
| ORM | SQLAlchemy 2.0 (async) | 用 Python 对象操作数据库 |
| 数据库 | PostgreSQL 16 | 关系型数据库 |
| 数据库迁移 | Alembic | 版本化管理数据库表结构 |
| 认证 | JWT + bcrypt | 用户登录和权限验证 |
| AI 接口 | DashScope (阿里云) | 调用 qwen-image-2.0 生成图片 |
| 部署 | Docker Compose | 一键启动所有服务 |
